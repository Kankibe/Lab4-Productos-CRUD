# Laboratorio de Aplicación CRUD

Fecha: 24/09/2026

## Contenido del Repositorio

Este laboratorio implementa una aplicación CRUD (Crear, Leer, Actualizar, Borrar) para el manejo de productos en C# con Windows Forms y SQL Server. El formulario principal muestra los productos en un DataGridView, permite buscar por nombre, agregar un producto nuevo con su imagen, seleccionar una fila para editarla o borrarla, y valida los datos (nombre, precio y cantidad) antes de guardarlos o actualizarlos en la base de datos.

## Tecnologías Utilizadas

- C# / .NET
- Windows Forms
- SQL Server
- Visual Studio 2026
